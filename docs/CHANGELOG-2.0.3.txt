PartyMod 2.0.3

Reviewed the rewritten mod against the original Mega Walls 100-player party screening purpose.

- Restored missing original screening behaviour: zero-game legendary reviews, quest/network-level kit exemptions, advanced first-game kits and all applicable FKD brackets.
- Kept the direct Hypixel API-key setup, configurable new-account kicking and /block add after confirmed kicks.
- Retained the login command-spam fix.
- Fixed interrupted stat checks, cancellation callbacks, request expiry, duplicate subscribers and rate-limit pause handling.
- Prevented pending, unavailable or stale stats from authorising automatic removal.
- Fixed duplicate removals, cancelled-block retries, queued auto-block toggles, dropped invitations and outdated readiness rounds.
- Fixed note loss on resizing, same-name rejoin input, UUID record migration and record-limit handling.
- Fixed review-queue filtering, dismissed-warning labels and cancelled-data counts.
- Improved OneConfig organisation by hiding irrelevant settings and removing deprecated dependency calls.
- Preserved incoming rendering states to reduce interference with other HUDs.
- Added checks against unsafe edited age thresholds and future/stale roster timestamps.
- Hardened the optional service's identity checks, connection bounds and response reads.

Verification: 98 Java tests and 11 Python tests passed. The final production JAR loaded in an isolated Forge 1.8.9 / Java 8 client with OneConfig and rendered a 100-player synthetic roster. Note resize/rejoin checks, native HUD editor opening and enable-disable-enable all passed.

Live Hypixel commands, real API responses and live-match HUD behaviour still need server testing. Replace older PartyMod JARs; keep only one installed copy.
