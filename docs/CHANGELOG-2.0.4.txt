PartyMod 2.0.4 — second review fixes

Purpose retained: organise 100-player Mega Walls parties, screen new joins using
Hypixel statistics, and present every applicable review reason. Direct API-key
setup, configurable new-account kicks, automatic /block add after a confirmed
kick, OneConfig settings, the organiser UI and optional HUD remain available.

- A temporary stats outage no longer removes a host approval. Actual reason
  changes and known UUID changes still invalidate relevant host decisions.
- Saved records keep their UUID ownership. An unresolved or different account
  using a previously owned name no longer inherits that account's notes/blocklist.
- New joins and local MW sightings recorded before UUID resolution are added
  once to existing history; they are no longer lost during the merge.
- Notes in the overflow buffer can merge into an existing UUID record. Retained
  long/secondary notes survive migration and reload. Deleting a resolved identity
  also removes its owned name aliases.
- The loader accepts the escaped-note files that the mod can legitimately write.
- A roster containing case variants of the same name cannot commit as complete.
  A ranked or marked player named None is no longer skipped as an empty row.
- Leadership transfer ends the old readiness round. Failed/cancelled readiness
  sends clear only their own round. Explicit self-leave/kick updates end the party.
- Rapid enable/disable notices show the latest state. Routine join bursts cannot
  replace an active operational-problem toast; their log entries are retained.
- Request cancellation triggered by an expired callback prevents another queued
  HTTP lookup from starting.
- Rendered player controls and confirmation dialogs are bound to the displayed
  membership, UUID and review evidence; a stale click is rejected.

Verification: 126 Java tests, 11 Python service tests, Java 8 production build,
and isolated Forge 1.8.9/OneConfig startup, rendering and action/input probes.
No live Hypixel server, real API key, real 100-player event or in-match HUD test.
